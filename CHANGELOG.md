# Changelog

All notable changes are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases use semantic versioning.

## [1.0.0] - 2026-09-16

### Added

- Deterministic 8×8 line-orientation image generator and eight-patch feature transform.
- Three-stage, shared-parameter, eight-qubit QCNN and specialized exact simulator.
- Qiskit circuit diagnostics and NumPy/Qiskit numerical parity tests.
- Exact occurrence-wise parameter-shift training with a two-parameter classical head.
- Matched logistic-regression, calibrated RBF-SVM, and MLP baselines.
- Repeated stratified evaluation, occlusion subgroups, and QCNN sensitivity probes.
- Complete artifact persistence, trusted-run inference, CLI, notebook, and Streamlit app.
- Unit/integration suite, Ruff checks, Python packaging, and GitHub Actions CI.
- Architecture, methodology, data card, model card, responsible-use, experiment, results, verification, and upload documentation.
