# Frozen reference-run artifacts

**Created by School of AI and School of QC**

These files were copied without modification from the single seed-42 run of `configs/default.json` performed for release 1.0.0 on 2026-09-16.

- `config.json` — resolved experiment settings.
- `dependency_versions.json` — reference software environment.
- `circuit_diagnostics.json` — logical circuit size, operations, and simulation workload.
- `summary_overall.csv` — mean and population standard deviation by model.
- `metrics_per_split.csv` — every model result for every held-out split.
- `split_wins_or_ties.csv` — descriptive accuracy wins or ties.
- `split_assignments.csv` — row membership for all three holdouts.
- `qcnn_training_history.csv` — epoch-level training traces.
- `qcnn_robustness.csv` — parameter-noise and finite-shot probes.
- `occlusion_subgroup_metrics.csv` — per-repeat occlusion diagnostic.
- `benchmark_report.md` — report generated by the benchmark.

The full timestamped run also produced generated images, patch features, individual predictions, fitted models, circuit text, and plots. Those larger/redundant artifacts are regenerated by:

```bash
quantum-cnn benchmark --config configs/default.json
```

Inspected documentation figures are stored in [`docs/assets`](../../docs/assets). See [`docs/RESULTS.md`](../../docs/RESULTS.md) for interpretation and limitations.
